⚠️ Legacy Project (2013–2014)
This is a PHP guild management system I built at ~19 years old with no formal CS education, no Stack Overflow, and no framework — just raw PHP and MySQL.

It contains every mistake you'd expect: SQL injection, plaintext password storage, hardcoded credentials, no foreign keys, and XSS "protection" via string replacement. None of this code should be used or referenced as practice.

Why it's still here: It's the oldest proof that I was writing code 12 years before my BSc. The contrast with my current thesis project https://github.com/balasis-org/task-manager-app  — a production-grade modular monolith on Azure with OAuth2, distributed locking, and Bicep IaC — is the point.

This repo exists as a timestamp, not a reference.
